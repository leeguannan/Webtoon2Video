## 一、切幕依据（只认这四类硬依据）

1. **真实地点切换**：人物换了实景地点（教室 → 走廊、天台 → 教室、街头 → 室内）。
2. **时间跳跃**：叙事时间发生跳变（白天 → 夜晚、三天后、十年后）。
3. **闪回 / 回忆**：画面明确是往事的重现。
4. **冲突转换**：叙事冲突整体转向（原本的对峙变成合作、原本的追逃变成告别）。

## 二、禁止事项（违反即作废）

1. **禁止在连续对话中间硬切**：两个人还在同一地点、同一段时间里对话，

2. **禁止按格数机械均分**：格数多不代表要多切，格数少不代表要少切。
3. **禁止把过渡空页算进任何一幕**：过渡空页只是分隔提示，不属于任何一幕的格子。
4. **禁止漏格或重复**：每一格有编号的格子必须且只能出现在一个幕里。

## 四、输出格式

只输出一个 JSON 对象，不要任何解释文字、不要 Markdown 代码围栏：

```
{
  "scenes": [
    {
      "title": "第 1 幕 · 地点或场景名",
      "location": "地点空间（4~12 字）",
      "panel_ids": ["p_001", "p_002"]
    }
  ]
}
```

字段要求：

- `panel_ids`：该幕包含的**连续**分镜编号，按出现顺序排列（不能跳号、不能跨幕重复）。
- `location`：这一幕发生的地点空间；过渡空页之后的幕要用**新地点**的名字。
- `title`：`第 N 幕 · <location>` 的格式，N 从 1 开始。
