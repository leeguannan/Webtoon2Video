【铁律一：严禁篡改故事去凑分镜】
- **上面「已定稿的故事正文」是唯一主干**。解说句必须讲这段正文里真实发生的事。
- 严禁为了消耗候选分镜而硬插废话、复述画面、或者改写故事走向。
- 每条解说句 **10~45 字**；本章条数**严格遵守上面的【本章解说条数预算】**（全话总条数以各章预算之和为准），不要超配额多写。
- 语气是连贯说书：句与句之间要能顺着念下来，标点自然。

【铁律二：按剧情顺位挑图配合】
- 每条解说句挑 **1~3 张**最贴合当下这句内容的 `panel_id`，从**候选清单里按时间顺序往后**挑。
- **精准匹配（Patch v4.19）**：这句讲的是谁、在哪、做了什么，就必须挂**讲这一点的格子**；
  不许拿一张“差不多”的图反复覆盖多句无关内容，也不许讲 A 事件却挂 B 事件的图。
- **只允许跳过纯粹重复的静态反应格**：本幕的关键动作、转折与「必保原话」必须讲到，
  无关 / 重复 / 低信息格可以跳过，宁缺毋滥。
- 讲连续心理或背景介绍时，多句可以连续停留在同一张核心主画面。
- `target_panel_ids` 里的 id 必须**原样照抄**候选清单里的 id。
- 全局顺序必须单调不减：后一条解说的分镜序号不能早于前一条。

【铁律二点五：纯字卡避让（Patch v3.1 Patch 10）】
- 候选清单里带 **`[纯字卡]`** 标记的分镜，**尽量跳过不选**：那只是一块内心独白文字框，
  选它就变成「白底黑字 PPT 朗读」。
- 内心独白与故事旁白**优先挂到相邻的人物表情 / 动作格**上；
  确实要用纯字卡的文字内容，就把它讲成人物此刻的**处境与选择**，而不是念字条本身。

【铁律二点七：`speaker_role` / `speaker_gender` 标定（Patch v3.1 Patch 10 / Patch v3.2 Patch 12）】
- 旁白叙述一律填 `"speaker_role": "narrator"`、`"speaker_gender": "unknown"`。
- **角色原话台词**（角色第一人称/口吻说出的独立对白句）才用角色声线：
  - `"speaker_role"` **优先填具体人物姓名**（如 `"恩彗"`、`"道振"`、`"继母"`）；
    没有登记姓名时才退回角色槽位：`"female_lead"` / `"male_lead"` /
    `"female_mature"` / `"male_antagonist"`。
  - `"speaker_gender"` 跟着填 `"male"` / `"female"`（确实分不清才填 `"unknown"`），
    这样「没单独配音色的角色」也能自动落到通用男声 / 通用女声。
- 带「恩彗心想：……」或第三人称转述的句子**仍然用 `"narrator"`**，避免人称与声线冲突。

【铁律二点八：中文双引号 + 旁白与台词分家（Patch v3.2 Patch 12）】
- **所有人物对话、心声原话一律使用中文双引号 `“…”`**；
  严禁出现单引号 `‘…’`、`'…'` 或英文直引号 `"…"`。
- **旁白引导与角色原话要拆成相邻的两条 Beat**：
  - 第一条只写旁白引导（`"道振平静说道："`），`speaker_role` 填 `"narrator"`，
    `pause_after_ms` 填 `60`（念完引导词立刻接角色声音）；
  - 第二条只写角色原话（`"“别怕，有我在。”"`），`speaker_role` 填说话人姓名，
    `speaker_gender` 填其性别。
- 不要把两者写进同一条 Beat（那样只能绑定一个音色，角色会自己念出引导词）。
- 系统会做确定性拆分兜底，但你主动拆好最省事。

【铁律二点八五：句间停顿与转折留白 pause_after_ms（Patch v4.6 / v4.8 / v4.9）】
- **引号引导词**（旁白接角色原话，如 `“道振平静说道：”`）：`50 ~ 80`（保持短停顿，念完立刻接角色声音，不可改大）；
- **普通叙述 / 连续动作 / 常规对话**（同一张分镜图内连续拆句）：`150 ~ 250`；
- **切到下一张新分镜图**（画面切换到底）：`400 ~ 450`（自动节奏留白的底线是 400ms，不要写得更短）；
- **段落换气口**（连续叙述段落结束）：`450 ~ 550`；
- **大转折 / 跨场景 / 悬念揭示 / 高潮短句**（时空跳转、秘密揭穿、关键证据曝光、震惊反问或悬念尾句）：
  `900 ~ 1200`（跨场景结尾约 `1150`，大转折约 `950`），全话控制在 6~10 处左右，宁缺毋滥，不要句句都标重停顿。

【铁律二点九：可选音效提示 `sfx_cue`（Patch v3.1 Patch 10）】
- 仅在**剧情高潮或明显的物理动作点**输出 1 个标准 key，普通对话与叙述留空或省略。
- 合法 key 只有这 7 个：`heart_thump` / `door_slam` / `whoosh` / `gasp` / `phone_msg` / `footstep` / `crash`。
- **全话最多 4~8 处，切忌每句都加**（宁缺毋滥，避免吵）。

【铁律三：tts_text 禁拼音】
- `tts_text` 是**整句送音文本**，不是单个词：字幕为脱敏字或特殊口语（如 `混X`、`靠X`）时，把脱敏字换成**标准汉字同音词**（如「混蛋」「混账」「靠北」）后，把**整句**写进 `tts_text`。
  - 正例：`narration_text` = 「他指使那个混X的！」→ `tts_text` = 「他指使那个混蛋的！」（整句）。
  - 反例：`tts_text` = 「混蛋」（只有被替换的那个词）——这样整条解说只会念出两个字，后面直接跳过。
- **严禁出现 `hùn xiǎo`、`jié zuò` 这类带声调或 ASCII 拼音字母**。
- 没有需要替换的字就**不要输出 tts_text**，而且**绝不要改动 narration_text**。

【铁律三之一：语气词与句中停顿标签（Patch v4.14，MiniMax Speech 2.8）】
- 只有当这句**确实需要**语气或停顿时，才写 `tts_text`；标签**只能写在 `tts_text` 里**，
  **严禁写进 `narration_text`**（字幕上不能出现 `(laughs)` 这种英文括号标签）。
- 官方语气词标签只有这 19 个，用半角括号紧贴文字：
  `(laughs)` `(chuckle)` `(coughs)` `(clear-throat)` `(groans)` `(breath)` `(pant)` `(inhale)`
  `(exhale)` `(gasps)` `(sniffs)` `(sighs)` `(snorts)` `(burps)` `(lip-smacking)` `(humming)`
  `(hissing)` `(emm)` `(sneezes)`。只挑贴合当下情绪的，别乱撒。
- 句中停顿用 `<#x#>`，x 是秒数（0.01 ~ 99.99，最多两位小数，如 `<#0.5#>`、`<#1.2#>`）。
- 全话用量参考：**语气词约 2~6 处、停顿约 1~4 处**，宁缺毋滥。
- `<#x#>` **必须夹在两段可发音文字之间**，**不可连用**（不要写 `<#0.5#><#0.8#>`），
  **不可放在句首或句尾**（句尾停顿请用 `pause_after_ms`）。
- 写了 `tts_text` 就必须写**含标签的完整整句**（把字幕整句连同标签一起写全），
  不能只写「标签 + 一个词」，否则这条只会念出那几个字。

【铁律三之二：单句语速波动 `speed_override`（Patch v4.13）】
- **普通叙述一律省略该字段或填 `null`**：全话语速以角色/默认语速为准。
- 只有在**节奏或情绪出现明显变化**的那一句才给值，用来微调这一句的语速：
  - 紧张、争吵、惊呼、加速推进：`1.08 ~ 1.20`；
  - 低沉、悲伤、回忆、情绪回落：`0.85 ~ 0.94`。
- 取值范围 `0.85 ~ 1.25`，**越靠近 1 越安全**；不要为了「有变化」而乱填。
- 全话约 **4~10 处**即可，其余留空。

【铁律三之三：全链路简体中文（Patch v4.13）】
- `narration_text` 与 `tts_text` 一律写**简体中文**，不要输出繁体字或港台用字。

【铁律三之四：`emotion_instruction` 是可选字段（Patch v4.19）】
- **默认省略这个字段**：绝大多数解说句用默认语气就够了，写满 10 条反而稀释了真正需要强调的那几句。
- 只有当这句的语气**确实特殊**（撕心裂肺的哭喊、压低声音的耳语、爆发式的怒吼）才写，
  一句话写清「语气 + 强度」（例：「压低声音，几乎是耳语」）。
- 写了就写一句，不要堆砌形容词；宁缺毋滥，全话 **0~6 处**即可。
