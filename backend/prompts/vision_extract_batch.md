## 任务

用中文描述每一格画面，并抽取对白气泡与音效。只描述**看得见**的内容，不要脑补剧情走向。

## 硬约束零：一律写简体中文（Patch v4.13）

- `scene_summary`、`dialogues[].text`、`dialogues[].speaker_guess`、`sfx_list` 一律用**简体中文**。
- 漫画原文若是繁体字或港台用字，**转写为简体**再输出（例如「這裡」→「这里」、「後臺」→「后台」）。
- 拟声词若原文是繁体，同样转成简体（`啪` / `轟` → `轰`）。
- **专有名词与角色名保留作品里的写法**，不要另造译名。

## 输出格式（严格输出 JSON，不要输出解释文字）

```json
{
  "panels": [
    {
      "panel_id": "{{TARGET_PANEL_IDS}} 的第一个",
      "scene_summary": "一句话概括画面内容（35~80 字，写清地点空间 + 主语 + 动作方向/对象 + 神态）",
      "dialogues": [
        {"speaker_guess": "角色名", "text": "气泡里的原文", "emotion": "calm"}
      ],
      "sfx_list": ["拟声词原文"],
      "focus_region": [0.1, 0.15, 0.85, 0.9],
      "is_transition_blank": false,
      "is_pure_text_card": false,
      "non_story_type": "none"
    }
  ]
}
```

**数组规则（硬性）**：

- `panels` 数组长度**必须等于 {{PANEL_COUNT}}**，一个面板对象都不多、一个都不少。
- `panels[i].panel_id` **必须**按 `{{TARGET_PANEL_IDS}}` 的顺序**逐一严格匹配**
  （第 1 个元素对应第 1 个面板 ID，以此类推），不得调换顺序、不得合并、不得漏写。
- 每个面板对象内部的字段含义与单格抽取完全一致。

字段说明：

- `dialogues[].emotion` 只能是 `calm` / `happy` / `angry` / `sad` / `shocked` / `whisper` / `tense` 之一。
- **必须区分「无尾矩形框」与「带尾巴对白气泡」**（Patch v4.0 Patch 18）：
  - **带尖角尾巴的对话气泡（Speech Bubble）**：必须**追踪气泡尖角尾巴（或气泡开口的朝向）指向哪位角色**
    来判定 `speaker_guess`——尾巴指向谁，这句话就是谁说的。
    即使那个人**只露出一点衣角、只有半张脸、或完全在画外**，也要结合上下文把 `speaker_guess`
    写成真实说话人（如 `父亲` / `病房中的男人` / `画外男声`）。
    **严禁因为画面主体是女主恩彗，就把别人骂她的话写进恩彗名下。**
  - **无尖角尾巴的矩形框（黑底白字框 / 白底黑字框）**：一律视为**心理独白或旁白**，
    `speaker_guess` 填 `角色名(内心独白)`（如 `女主(内心独白)`）或 `旁白`，
    **禁止**标成该角色当场说出口的口头台词。
  - 两类都要抽全：同一格里既有独白框又有气泡台词时，**两条都要出现在 `dialogues` 数组里**。
    旁白框（无人物名、纯叙述文字）填「旁白」。
  - 判定口诀：**先看尾巴，再看框**。尾巴是唯一的「谁在说」证据，气泡在画面上的上下位置**不是**证据。
  - **批量场景补充**：相邻几格往往是同一个人的连续发言，若某格的说话人需要靠上下文推断，
    就用上一格的说话人 + 上一格的动作延续来判断（这是允许的上下文利用），但**绝不能**
    把上一格的台词搬进本格。
- `focus_region` 是画面中主要动作或主体的归一化坐标 `[x1, y1, x2, y2]`（0~1）；无法判断时给 `null`。
- `is_transition_blank` 仅在该格为纯白/过渡空页时为 `true`。
- `non_story_type` 只能是 `none` / `transition_blank` / `copyright_notice` / `promo_banner` / `sfx_only` 之一，普通剧情格一律填 `none`。
- **片尾非剧情页判定（任何语言：中/英/韩/日都适用）**：若该格是「LINE WEBTOON / WEBTOON 官方版权声明、著作权或防盗版警告、休刊公告、求赞/订阅/关注推广尾页、平台引流横幅」，`non_story_type` 填 `copyright_notice`（版权/防盗版警告）或 `promo_banner`（休刊/求赞/推广），并**同步把 `is_transition_blank` 置为 `true`**；这类格子没有剧情内容，`scene_summary` 简述其用途即可。
- 漫画正片中的暗黑画面（夜景、黑色背景的剧情格）不属于版权页，`non_story_type` 仍填 `none`，严禁误标。
- **拟声词/特效字判定（Patch v3.0-6，最高优先级）**：画面里的拟声词与特效字（例如 `心驚`、`驚`、`啪`、`咚嗒`、`咔嚓`、`轰`、`嘶` 等）**一律放进 `sfx_list`，绝不能当成人名、也不许写进 `dialogues`**。
  - `心驚` 是「心里一惊」的拟声写法，**不是角色名**：`speaker_guess` 里绝不允许出现「心驚」「驚」这类词；更不允许出现「心——敬馬」「心驚（人名）」之类的臆造拆分。
  - 若整格**只有拟声词/气氛特效、没有人物动作、没有对白气泡**，则 `non_story_type` 填 `sfx_only`（此时 `dialogues` 为空数组，`scene_summary` 简述画面氛围即可）。
    （Patch v4.0 Patch 18 补充：**暗黑高潮格除外**——深黑底 + 红光 / 火光剪影的高潮格即使只有拟声词也**不得**填 `sfx_only`，见硬约束六。）
  - 若同一格里既有拟声词又有真实对白：拟声词进 `sfx_list`，对白照常进 `dialogues`，`non_story_type` 填 `none`。
- 没有对白时 `dialogues` 给空数组；没有拟声词时 `sfx_list` 给空数组。

## 硬约束一：人物发色与光照必须剥离（Patch v3.1 Patch 10）

- 描述人物外观时，**必须区分「固有发色/发型/衣着」与「环境打光」**：
  画面里的红色可能是警示灯、霓虹、夕阳或滤镜，**不等于这个人是红发**。
- 反例（真机踩坑）：红光地下室里，浅灰长发的少女被写成「红发成年女性（继母）」，
  下游直接把两个角色认成一个人——**这是绝对不允许的**。
- 正确写法：写「浅灰长发少女，在红色警示灯下被照得满脸红光」，
  而不是「红发女人」；只有头发**本身就是**红色/棕红/粉色等颜色时才写红发。
- 同理，环境光偏蓝/偏绿/偏暗时，也不要据此改写人物的固有发色与衣着颜色。

## 硬约束二：`scene_summary` 必须交代所处地点空间（Patch v3.1 Patch 10 / Patch v4.19）

- `scene_summary` **开头**先点明场景地点空间，例如「病房内」「医院走廊」「红光地下室」
  「客厅沙发」「公司工位」，再描述画面里发生的事。
- 目的：让下游（4A 故事反写 / 4B 拆拍）能判断「这个角色此刻到底在哪个空间」，
  从而不会把一直待在病房的角色写成突然出现在地下室。
- 不同空间的画面不得混写；人物不在同一空间时，摘要里要能看出来。
- **Patch v4.19：长度放宽到 35~80 字，且必须写齐四要素**——
  ① **地点空间**（开头点明）② **主语**（谁／哪个人物，用名字或明确身份）
  ③ **动作方向/对象**（朝谁做、往哪儿动、对什么物件）④ **神态**（表情与情绪）。
  - 反例（不合格，20~40 字的旧写法）：「少女抬头」「走廊里有两个人」——没有动作对象、没有神态，
    下游拿去写故事时只能猜。
  - 正例：「红光地下室内，少女攥紧拳头朝绑匪方向逼近半步，眼神发狠却带着犹豫。」
  - 四要素写不齐时，宁可多写细节到 80 字，也不要凑成一句空话。

## 硬约束三：`is_pure_text_card` 判定（Patch v3.1 Patch 10）

- 若该格主体**只是一块文字框 / 内心独白卡片 / 纯黑或纯白底的大段文字**，
  画面里**没有人物面部特写、也没有肢体动作**，则 `is_pure_text_card` 填 `true`。
- 若格内有角色（哪怕只是侧脸、背影、手部动作）或角色的对白气泡，填 `false`。
- 这类纯字卡下游会被打上 `[纯字卡]` 标签并尽量跳过，避免出现「白底黑字 PPT 朗读」。

## 硬约束四：对白用中文双引号 + 摘要不写静态摆设（Patch v3.2 Patch 12）

- `dialogues[].text` 里的**原文一律使用中文双引号 `“…”`**：
  - 气泡原文若带引号（`"别怕"` / `'别怕'`），统一改写成 `“别怕”`；
  - 气泡原文本身没有引号时**不要自己加引号**（引号是下游拆对白时用的）。
  - 下游要靠中文双引号把「旁白引导」和「角色原话」拆开、由不同声线念，
    引号形态不统一就会把台词混进旁白。
- `scene_summary` **只写有人物动作、表情或剧情信息的画面**；
  纯静态摆设（"桌上静静躺着一台笔记本电脑""金属柜、箱子、散落的线缆"）
  不要罗列成清单——一句话概括场景与正在发生的事即可。

## 硬约束五：动作耦合拟声词必须写进 `scene_summary`（Patch v4.0 Patch 18）

- 表示**物理动作或状态骤变**的拟声字 / 特效字（`啪！` 扇耳光、`咚` 倒地、`哐当` 撞上、
  `抓住`、`摔碎`、`推门` 等），除了放进 `sfx_list`，**还必须在 `scene_summary` 里
  用一句话把「谁对谁做了什么」写清楚**。
- 示例：
  - 只写 `sfx_list: ["啪！"]` → **不合格**（下游不读 `sfx_list`，这场冲突会凭空消失）。
  - 正确写法：`scene_summary` 写「继母抬手扇了道振一耳光，道振脸颊瞬间泛起红印」；
    `sfx_list: ["啪！"]`。
  - 正确写法：`scene_summary` 写「被绑男子在火海中轰然倒下，火光映红他半边脸」。
- 判定口诀：**拟声字 = 动作的结果**。凡是「有结果的物理动作」，摘要里必须有主语和动作。

## 硬约束六：暗黑高潮格严禁标成空页 / 纯字卡 / 纯拟声（Patch v4.0 Patch 18）

- **深黑底 + 血红警示光 / 火光剪影 + 六边形或黑底对白框**，属于**高潮剧情格**，
  必须按普通剧情格输出：`is_transition_blank = false`、`is_pure_text_card = false`、
  `non_story_type = "none"`。
- 这类格子里往往有**全篇最关键的一句台词**（反转、遗言、揭穿），
  标成空页 / 纯字卡 / `sfx_only` 会让这一格在下游被整格剔除，故事直接断在半句。
- 「黑底 + 白色描边对白框」不等于纯字卡：只要框里有**人物剪影、动作或情绪**，
  就不是纯字卡（纯字卡的判据仍然是「画面里没有人物面部特写、也没有肢体动作」）。
- 判别口诀：**黑得越深，越可能是高潮**；空页是「什么都没有」，高潮格是「黑但有戏」。
