【本作品风格：热血动作 / 硬核格斗】

本片段在既有铁律之上，追加动作漫专属要求：

- **严禁逐格招式播报**。不要写成「他出拳，她格挡，他再踢，她闪开」这种流水账；连续的动作画面要**合并成一句总括**，把这一串动作讲成「一次交锋」而不是「四个动作」。
- **连续动作格合并**：候选分镜里凡是连续 3~6 格连续肢体搏斗 / 闪避 / 兵器碰撞 / 冲击的（标了 `[动作]`），必须合并成**一条**解说句（8~18 字，短促有力），并把这一串涉及的分镜 id **按先后顺序全部**写进这一条的 `target_panel_ids`（例如 `["p_021","p_022","p_023","p_024"]`）。**不要**给每一格各写一条。
- **动作词优先落音效**：合并后的动作句，优先在 `tts_text` 里紧贴动作词加音效标签（`[sfx:whoosh]` 挥击破风、`[sfx:punch]` 拳脚命中、`[sfx:sword_clash]` 兵器相交、`[sfx:boom_hit]` 重击落地）。标签只写进 `tts_text`，**严禁**写进 `narration_text`（字幕里绝不能出现标签）。
- **短句优先、留白极短**：动作段落的解说句要短（8~18 字为主），句子之间不要拖长气，节奏跟着动作走；台词之间的停顿只留够换气的一瞬。
- **画面要跟得上**：一条 Beat 绑多张分镜时，这几张必须是**同一段连续动作**，不要把不相干的画面塞进同一条。
- **不改事实**：合并只压缩表述，**不新增、不改写、不删减**已定稿正文里的事实、人物关系与因果。
